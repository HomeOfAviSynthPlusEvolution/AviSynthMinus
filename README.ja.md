# AviSynthMinus

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

AviSynthMinus は、AviSynth+ から派生した音声・映像フレームサーバーです。スクリプトで編集、フィルター処理、形式変換を組み合わせ、エンコーダーやプレーヤーなどのアプリケーションに、処理後の音声・映像を必要に応じて供給します。あらかじめ中間ファイル全体を生成する必要はありません。

本プロジェクトでは安定版とメインライン版を分け、保守的な修正を速やかにリリースしながら、新機能や大規模な内部改善の開発を進めます。自動テストを重視し、既存の AviSynth スクリプトやプラグインとの互換性維持を目指すとともに、引き続き上流の開発を追い、関連する改善を取り込んでいきます。

## このフォークを作成した理由

AviSynthMinus は、開発とリリースの進め方に対する考え方の違いから生まれました。上流の AviSynth+ では、主に単一のメインブランチで開発が進み、修正、新機能、大規模な内部変更が同じ開発ラインに蓄積されます。正式リリースの間隔が長くなると、ユーザーが正式版を通じて修正を受け取るまでの待ち時間も長くなります。安定版の保守とメインラインの開発を分けることで、検証済みの修正を独立してリリースしながら、大きな変更の開発とテストを継続できるようにしたいと考えています。

このフォークでは、引き続き AviSynth+ の開発を追い、適切な修正や改善を取り込んでいきます。上流で開発中の機能については、完成後に取り込むことを基本とし、互換性のない実装が生まれることをできるだけ避けます。また、出典と貢献者のクレジットを保持したうえで、上流が本プロジェクトの修正や改善を採用することも歓迎します。

## リリースチャネル

AviSynthMinus では、バージョン番号 `major.minor.patch` のマイナーバージョン（`minor`）で区別する、2 つのリリース系列を維持する予定です。

| チャネル | マイナーバージョン | 位置付け |
|---|---|---|
| 安定版（Stable） | 偶数。例：`0.2.x` | 不具合修正と保守的な改善を中心とし、動作の変化を抑えたいユーザー向けです。 |
| メインライン版（Mainline） | 奇数。例：`0.1.x`、`0.3.x` | 新機能や大規模な内部変更を導入し、新しい開発成果を試してフィードバックを提供したいユーザー向けです。 |

リリースチャネルとプレリリースの状態は別々に示します。メインライン版が必ずしもプレリリースとは限らず、安定版でもテスト用のリリース候補を先に提供する場合があります。具体的な状態、変更点、既知の問題は、各バージョンのリリースノートを確認してください。

有用な修正を早く届けるため、小規模で比較的頻繁なリリースを目指します。固定のリリース日程は設けず、変更の準備状況とメンテナーが確保できる時間に応じてリリースします。

## ダウンロードとインストール

[Releases](https://github.com/HomeOfAviSynthPlusEvolution/AviSynthMinus/releases) からバージョンを選び、変更点、インストール要件、既知の問題を確認してください。

Windows では、用途に応じて mod インストーラーまたはファイルのみのパッケージを選べます。現在の mod インストーラーは Windows 10 以降の x64 システム向けで、公式の AviSynth+ 3.7.5 がインストール済みである必要があります。インストール済みの x86 および／または x64 コアを置き換え、既存のプラグインやその他のコンポーネントを保持します。未インストールのアーキテクチャを追加することはありません。

mod インストーラーは置き換えるコアをバックアップし、アンインストール時に復元可能かどうかを確認します。インストールやアンインストールの前に、AviSynth を使用しているアプリケーションを終了してください。公式の AviSynth+ を更新またはアンインストールする前に、mod をアンインストールしてください。

ファイルのみのパッケージは、手動で配置する場合や実行環境を自分で管理するユーザー向けです。Windows、Linux、macOS で利用可能なアーキテクチャと実行時の依存関係については、各バージョンの配布ファイルとリリースノートを確認してください。AviSynth を読み込むアプリケーションと同じアーキテクチャを選択してください。

## 互換性とプラットフォーム

AviSynthMinus は、既存の AviSynth スクリプトやプラグインとの互換性維持を目指し、可能な限り AviSynth+ との API・ABI 互換性を維持します。互換性を重視することは、内部実装を固定することではありません。アーキテクチャや動作を改善する際は既存の使い方への影響を評価し、必要な非互換変更と移行方法をリリースノートに明記します。

本プロジェクトは Windows、Linux、macOS を対象としていますが、検証の範囲は OS やプロセッサーのアーキテクチャによって異なる場合があります。自動ビルドの成功は、その環境でコードがコンパイルできることを示すものであり、すべてのスクリプト、プラグイン、ホストアプリケーションの実行時動作を検証済みであることを意味しません。プラグインやホストアプリケーションにも、それぞれ対応プラットフォーム、アーキテクチャ、実行環境の要件があります。

互換性の問題の報告を歓迎します。AviSynthMinus のバージョン、OS とアーキテクチャ、ホストアプリケーションと関連プラグインのバージョン、問題を再現できる最小限のスクリプトを添えてください。同じ使い方で AviSynth+ と動作が異なる場合は、比較に使用したバージョンと結果も記載してください。

## クイックスタート

インストール後、`version.avs` という名前のプレーンテキストファイルを作成し、次の内容を記述します。

```avs
Version()
```

AviSynth スクリプトの読み込みに対応したプレーヤー、エディター、エンコーダーでこのファイルを開いてください。正常に動作すると、バージョン情報を表示する映像が生成され、ホストアプリケーションが実際に読み込んだコアのバージョンを確認できます。この例では、外部のメディアファイルや追加のプラグインは不要です。

`.avs` ファイルには音声・映像の処理手順を記述し、ホストアプリケーションが読み込んで実行します。自分のメディアファイルを処理する場合は、入力形式に適したソースフィルターやプラグインを選び、編集やリサイズなどの処理を追加します。

## ビルドとテスト

本プロジェクトは CMake を使用し、C++17 対応のコンパイラーを必要とします。以下のコマンドはリポジトリのルートで実行してください。コアライブラリのみをビルドし、同梱の外部プラグインはコンパイルしません。生成されたコアは、互換性のあるプラグインを通常どおり読み込めます。

**Windows（Visual Studio 2026、x64）：**

```powershell
cmake -S . -B build/core -G "Visual Studio 18 2026" -A x64 -DBUILD_SHARED_LIBS=ON -DENABLE_TESTS=OFF -DENABLE_PLUGINS=OFF
cmake --build build/core --config Release --parallel
```

Windows では clang-cl でビルドすることもできます。処理内容によっては、clang-cl によるビルドが MSVC によるビルドより高い性能を示す場合があります。実際の性能はコンパイラーのバージョン、ビルドオプション、処理内容によって変わるため、実際のワークロードで比較することをお勧めします。

**Linux / macOS（Ninja と適切な C++ ツールチェーンが必要）：**

```sh
cmake -S . -B build/core -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=ON -DENABLE_TESTS=OFF -DENABLE_PLUGINS=OFF
cmake --build build/core --parallel
```

**テストの実行：**

リポジトリには Visual Studio 2026 x64 向けのテストプリセットが用意されています。テスト構成では静的コアライブラリを使用し、初回の構成時に Git 経由で GoogleTest と xxHash をダウンロードします。そのため、Git のインストールと依存先リポジトリへのアクセスが必要です。

```powershell
cmake --preset msvc-release
cmake --build --preset msvc-release --parallel
ctest --preset msvc-release
```

他のツールチェーンでは、別のビルドディレクトリで `-DENABLE_TESTS=ON -DBUILD_SHARED_LIBS=OFF -DENABLE_PLUGINS=OFF` を指定してテストを構成し、CTest で実行できます。テストはコアとスクリプトの動作、音声・映像変換、フィルター、回帰ケースを対象としており、開発に伴って対象範囲を継続的に調整しています。

## 開発とコントリビューション

AviSynthMinus は現在、メンテナーが主導して開発しており、技術方針、変更の採否、最終的なリリースに責任を持ちます。不具合報告、改善提案、コードの貢献、技術的な議論を歓迎します。新機能、互換性の変更、大規模なアーキテクチャ変更については、まず Issue で目的と方針を相談することをお勧めします。

本プロジェクトでは、コードの実装、テストの作成、コードレビューなどに AI を活用しています。メンテナーが指針を示し、変更を評価し、最終的に採用・リリースする内容に責任を持ちます。貢献の際は、解決する問題、実装方針、検証方法を明確に説明してください。AI を利用した場合は、その関与についても正確に記載してください。

問題の報告には [GitHub Issues](https://github.com/HomeOfAviSynthPlusEvolution/AviSynthMinus/issues) を利用し、可能な限り再現例を添えてください。修正を提出する際は、元の問題を再現し、修正を確認できる回帰テストの追加を推奨します。技術的な意見の相違は公開の場で議論できますが、プロジェクトの方針とマージの可否はメンテナーが最終的に判断します。
